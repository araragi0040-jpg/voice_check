# 歌い方タイプ診断 v002

歌うときの認知・聴覚・発声の傾向を、4つの能力から簡易チェックするブラウザアプリです。

- 脳内再生力
- 音程記憶力
- 音程識別力
- 発声変換力

## v002 の主な変更

1. 質問20問を全面見直し
   - 1つの質問に複数能力が混ざりすぎないよう整理
   - 4能力を交互に出し、能力名を質問画面では非表示
   - 脳内再生では「鮮明さ」と「意図的な操作」の両方を見る構成

2. 音声を聞き取りやすく改善
   - 小さかった単一サイン波を、スマホでも聞きやすい複合音へ変更
   - テスト音量スライダーを追加
   - 診断開始前に音量確認が可能

3. 発声テストを作り直し
   - 「マイク確認 → 基準音 → 声の測定」の3段階
   - マイク入力レベルを可視化
   - 入力が小さすぎる場合に案内
   - 音程検出を正規化自己相関方式に変更し、安定性を改善
   - 声の中心音程だけでなく、発声中の安定度も軽く評価

4. 結果表示を改善
   - 実技を行った能力は「自己評価＋実技」
   - スキップした能力は「自己評価のみ」と明示
   - 少数試行の簡易テストであることを結果画面でも説明

## 使い方

`index.html` を開けば質問・音声再生は利用できます。

発声テストのマイク機能はブラウザのセキュリティ制約があるため、GitHub Pages / Vercel / Cloudflare Pages など HTTPS のURLで公開して利用することを推奨します。

## GitHub への配置

このフォルダ内の以下3ファイルを同じ階層に配置してください。

- `index.html`
- `styles.css`
- `app.js`

静的サイトなのでビルドは不要です。

## 注意

本ツールは医療・心理検査、能力検査の標準化された診断ではありません。歌唱練習の方向性を整理するための簡易チェックです。今後、利用者データを蓄積して質問・配点・テスト難易度を調整する余地があります。
