# 歌い方タイプ診断 v001

質問20問 + 音程識別 + 音程記憶 + 発声変換（マイク）の簡易Web診断です。

## 起動
- `index.html` をブラウザで開くだけでも質問・聴覚テストは動きます。
- **マイクテストはブラウザ仕様上 HTTPS または localhost が推奨**です。
- GitHub Pages / Vercel / Netlify 等へそのまま配置できます。

## 診断軸
1. 脳内再生力
2. 音程記憶力
3. 音程識別力
4. 発声変換力

## スコア
- 質問：1〜5段階を0〜100換算。
- 音程識別：質問55% + 実測45%。
- 音程記憶：質問65% + 実測35%。
- 発声変換：質問50% + マイク実測50%。
- 脳内再生：v001では質問のみ。

※スコアとタイプ分類はv001用のヒューリスティックです。研究用・医療用の標準化尺度ではありません。

## ファイル
- `index.html` UI
- `styles.css` スタイル
- `app.js` 質問・音声生成・簡易ピッチ検出・スコアリング
