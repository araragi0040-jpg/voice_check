# リズムずれ原因チェック v003

テンポ・リズムがズレる理由を「リズム感」という一語でまとめず、以下の5要素＋補助要因に分けて見るブラウザアプリです。

- 拍知覚：拍を見つけ、ズレに気づく
- 外部同期：聞こえている拍へ動作を合わせる
- 内的テンポ保持：外部クリックが消えても周期を保つ
- リズム記憶：短い時間パターンを保持・再現する
- ズレ補正：テンポ変化へ追従する
- 脳内再生：内的保持を支える可能性がある補助プロフィール（自己評価）

## v002からの主な変更

- 「歌唱・音程」中心から「テンポ・リズム」中心へ全面変更
- マイクを廃止
- 質問18問をリズム用に再設計
- Beat alignment型の拍知覚テスト
- メトロノーム同期タッピング
- 8拍クリック＋8拍無音のsynchronization-continuation課題
- 途中テンポ変更への追従課題
- 短いリズムパターンの記憶・再現課題
- 脳内再生と内的テンポ保持の組合せ解釈
- 原因候補TOP3と優先練習を自動提示
- ブラウザ端末差を考慮し、絶対的な位相差よりタップ間隔の安定性を重視
